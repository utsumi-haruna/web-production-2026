## 企画

架空のヘアサロンのホームパージを作成

### ターゲット

最近開業したヘアサロン (Élan)　店のホームパージが欲しい

### 課題

見やすさを損なわず、お洒落な印象のあるホームページにしたい

## 制作工程

1. ホームページに必要な情報を整理
2. 情報の配置、大まかなデザインを考える
3. 画像を探し、細部までデザインする
4. コーディング
5. 動作確認・修正
